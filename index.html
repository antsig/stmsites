Panduan Pengaturan & Penggunaan Admin

Petunjuk operasional lengkap untuk pengelola sistem dan guru koordinator STEM.

1. Cara Mengambil URL Logo dari Google Drive

Jika logo sekolah atau gambar kartu disimpan di Google Drive, lakukan langkah berikut agar gambar dapat tampil secara publik:

  1. Upload gambar logo ke Google Drive.
  2. Klik kanan pada file gambar > Bagikan (Share) > ubah Akses Umum menjadi "Siapa saja yang memiliki link" (Anyone with link).
  3. Salin ID file dari link tersebut (contoh link: https://drive.google.com/file/d/1A2B3C4D5E6F/view?usp=sharing).
  4. Ubah format link menjadi direct download link:
    https://drive.google.com/uc?export=view&id=ID_FILE_ANDA
  5. Tempelkan format link tersebut ke kolom URL Logo di Pengaturan Admin.

2. Standar Format Tautan Media Interaktif

  • Video YouTube: Gunakan link watch biasa atau link pendek (misal: https://www.youtube.com/watch?v=...).
  • Simulasi Sains / Matematika PhET: Salin link langsung simulasi HTML5 dari phet.colorado.edu.
  • Simulasi Coding Blockly / Scratch: Gunakan tautan project online (misal: https://blockly.games/maze).
  • Dokumen / PDF Panduan Praktikum: Simpan file PDF di Google Drive dengan akses Anyone with link.

3. Mengelola Materi Massal Langsung di Google Sheets

Anda dapat mengedit atau mengimpor ratusan materi sekaligus langsung melalui lembar Google Spreadsheet yang terhubung pada sheet Materi. Kolom yang tersedia:

id | stem_category | title | grade | media_type | media_url | thumbnail_url | description | mission_goals | mission_steps | mission_reflection | created_at

Panduan Deploy Web App ke Google Apps Script

Langkah lengkap menerbitkan portal ini secara gratis menggunakan Google Spreadsheet & Apps Script (Rp 0/bulan).

Langkah Penerapan ke Akun Google Anda:

METODE TERMUDAH (HANYA 2 BERKAS DI APPS SCRIPT):

Anda cukup membuat 2 berkas saja di editor Apps Script:

  1. Berkas Script: Code.gs — klik tab Code.gs di bawah, lalu klik Salin Kode Ini.
  2. Berkas HTML: index — klik tab 📦 index.html (Standalone 1-File) di bawah, lalu klik Salin Kode Ini.
✨ Seluruh CSS, modal admin, dan logika JavaScript sudah terintegrasi rapi dalam berkas standalone ini!
  1. Buka Google Spreadsheet Baru (sheets.new) dan beri judul, misal: Database Portal STEM Sekolah. Biarkan sheet kosong.
  2. Pada menu atas Spreadsheet, klik Ekstensi (Extensions) > pilih Apps Script.
  3. Salin kode ke Apps Script:
    • Metode Standalone (Disarankan): Buat file Script Code.gs dan file HTML index.
    • Metode Modular (5 Berkas): Buat Code.gs dan 4 file HTML: index, styles, admin, scripts (ketik nama tanpa .html).
  4. Tekan tombol disket Simpan proyek (Ctrl + S).
  5. Klik tombol biru Terapkan (Deploy) di kanan atas > pilih Penerapan baru (New deployment):
    • Jenis: Aplikasi web (Web app)
    • Jalankan sebagai: Saya (email Anda)
    • Siapa yang memiliki akses: Siapa saja (Anyone) (wajib agar siswa dapat membuka tanpa login khusus).
  6. Klik Terapkan > lakukan otorisasi izin akun Google (klik Advanced / Lanjutan > Go to Portal STEM (unsafe) > Izinkan), lalu salin URL Web App yang dihasilkan!
⚠️ PENTING: Cara Memperbarui Kode (Agar Tidak Freeze di Versi Lama):
Jika Anda mengedit/menempelkan kode baru di Apps Script, menekan Ctrl+S saja TIDAK memperbarui URL Web App. Wajib klik Deploy > Manage deployments > Edit (ikon pensil) > Versi: New version > Deploy!

Skrip Lengkap Berkas Proyek:

Tipe: Script (.gs) | Nama di editor: Code.gs
