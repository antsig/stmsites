Akses Terbuka & Ramah Anak (Tanpa Login)

Anak Anda dapat langsung membuka portal ini melalui HP, tablet, maupun laptop tanpa perlu membuat akun atau memasukkan email pribadi.

Dampingi Eksperimen Praktikum Mandiri

Materi Engineering dan Science dilengkapi instruksi bahan rumah tangga yang mudah didapat (seperti botol plastik bekas, kertas lipat, atau balon). Dampingi anak saat melakukan percobaan untuk menumbuhkan rasa ingin tahu (*curiosity*).

Diskusikan Bagian Refleksi Bersama

Gunakan pertanyaan refleksi pada jendela misi untuk mengajak anak berdiskusi ringan setelah menonton simulasi atau video pembelajaran.

Media Apersepsi & Pemantik Belajar

Gunakan kartu STEM sebagai pembuka pelajaran di kelas dengan menayangkan video pendek atau simulasi interaktif (misalnya simulasi molekul PhET atau tantangan labirin robot) di proyektor kelas.

Penyelarasan dengan Pembelajaran Berbasis Proyek (PjBL)

Langkah misi pada kartu Engineering dapat dijadikan lembar panduan proyek kelompok siswa untuk melatih kerjasama dan berpikir kritis.

Tambah & Kustomisasi Materi Sendiri

Guru pemegang PIN Admin dapat menambahkan materi baru yang sesuai dengan RPP atau Modul Ajar mingguan melalui menu Admin.

Apakah materi simulasi bisa dijalankan langsung di smartphone?
Ya, seluruh tautan simulasi (seperti PhET Interactive Simulations dan Blockly Games) dirancang berbasis HTML5 sehingga dapat dibuka langsung di browser Google Chrome / Safari smartphone tanpa perlu install aplikasi tambahan.
Bagaimana jika link video atau simulasi tidak dapat dibuka?
Pastikan perangkat terhubung dengan koneksi internet yang stabil. Jika video YouTube dicekal oleh jaringan sekolah, guru/admin dapat mengganti link materi ke Google Drive video melalui Halaman Admin.
Bagaimana cara menghubungi kontak sekolah jika ada kendala?
Nomor WhatsApp dan email sekolah tercantum pada bagian bawah portal ini dan dapat dihubungi pada jam kerja operasional sekolah.

Panduan Pengaturan & Penggunaan Admin

Petunjuk operasional lengkap untuk pengelola sistem dan guru koordinator STEM.

1. Cara Mengambil URL Logo Sekolah dari Google Drive

Jika logo sekolah disimpan di Google Drive, lakukan langkah berikut agar gambar dapat tampil secara publik:

  1. Upload gambar logo ke Google Drive.
  2. Klik kanan pada file gambar > Bagikan (Share) > ubah Akses Umum menjadi "Siapa saja yang memiliki link" (Anyone with the link can view).
  3. Salin ID file dari link tersebut (contoh link: https://drive.google.com/file/d/1A2B3C4D5E6F/view?usp=sharing).
  4. Ubah format link menjadi direct download link:
    https://drive.google.com/uc?export=view&id=ID_FILE_ANDA
  5. Tempelkan format link tersebut ke kolom URL Tautan Logo Sekolah di Tab Pengaturan Logo.

2. Standar Format Tautan Media Interaktif

  • Video YouTube: Gunakan link watch biasa atau link pendek (misal: https://www.youtube.com/watch?v=... atau https://youtu.be/...).
  • Simulasi Sains / Matematika PhET: Kunjungi situs phet.colorado.edu, pilih simulasi HTML5, lalu salin link URL langsung simulasinya.
  • Simulasi Coding Blockly / Scratch: Gunakan tautan project online (misal: https://blockly.games/maze atau https://scratch.mit.edu/projects/...).
  • Dokumen / PDF Panduan Praktikum: Simpan file PDF di Google Drive, atur izin publik Anyone with link, lalu tempelkan link tautannya.

3. Mengelola Materi Massal Langsung di Google Sheets

Anda juga dapat mengedit atau mengimpor ratusan materi sekaligus langsung melalui lembar Google Spreadsheet yang terhubung. Buka spreadsheet database Anda, lalu buka lembar Materi. Kolom yang tersedia:

id | stem_category | title | grade | media_type | media_url | thumbnail_url | description | mission_goals | mission_steps | mission_reflection | created_at

Panduan Deploy Web App ke Google Apps Script

Langkah mudah menerbitkan aplikasi ini secara gratis menggunakan akun Google Anda.

4 Langkah Deploy Mudah:

  1. Buka Google Spreadsheet Baru di browser Anda dan beri nama (misal: Database Portal STEM).
  2. Pada menu atas Spreadsheet, klik menu Ekstensi (Extensions) > pilih Apps Script.
  3. Di dalam editor Apps Script:
    • Ganti isi file Code.gs dengan kode backend di bawah.
    • Klik ikon + di samping Berkas > pilih HTML > beri nama berkas persis index > tempelkan seluruh kode HTML di bawah.
  4. Klik tombol biru Terapkan (Deploy) di kanan atas > pilih Penerapan Baru (New Deployment):
    • Pilih jenis: Aplikasi Web (Web App).
    • Jalankan sebagai: Saya (Me / Akun Anda).
    • Siapa yang memiliki akses: Siapa saja (Anyone).
    • Klik Deploy dan salin URL Web App yang dihasilkan!
